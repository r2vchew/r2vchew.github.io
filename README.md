# r2vchew.github.io

This is Vince and Codex's clean shared workspace.

Start new work in a clearly named top-level folder. Keep each piece of work self-contained, document decisions in that folder, and leave the repository root tidy.

## Quick start

1. Create a folder for the work.
2. Add a concise `README.md` describing its purpose and how to run it.
3. Add a `STATUS.md` when the work has an ongoing operational state.

The previous site contents are preserved only in the `archive/pre-clean-slate-2026-07-25` branch.
